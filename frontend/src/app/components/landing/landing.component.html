Flujo de autorización OAuth2 / OIDC con MSAL Browser v3. MsalGuard protege las rutas de Angular y MsalInterceptor inyecta automáticamente el Bearer Token en cada solicitud al API Gateway.

Resource Server en Spring Boot

BFF / Backend desacoplado desplegado en instancias AWS EC2. Valida criptográficamente la firma digital del token con los endpoints JWKS de Microsoft, verificando emisor (issuer) y audiencia (audience).

Control de Acceso por Roles (RBAC)

Mapeo del claim roles en Spring Security. El rol 'Admin' autoriza la creación, modificación y eliminación (POST/PUT/DELETE), mientras que usuarios estándar cuentan con acceso de solo lectura (códigos 401 y 403 RFC-7807).
